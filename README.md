An incremental colony-management game. You are an Overseer: you build the
place, keep the lights on and the people fed, and try not to let it fall
apart.

**This is an unfinished work in progress.** It is rough in places, some of it
is deliberately half-built, and it is being changed constantly. This repo
holds playtest builds only — the source code is private and is not published
here.

## Download

Grab the latest `.zip` from the [Releases page](../../releases/latest), unzip
it anywhere, and run `ClickerCity.exe`.

- Windows only for now.
- Nothing to install. No engine, no dependencies.
- Keep `ClickerCity.exe` and `ClickerCity.pck` in the same folder — the game
  will not start without both.
- Windows will warn you it does not recognize the app, because the build is
  not code-signed. Click **More info** → **Run anyway** if you are happy to.

## Playing it

Press **M** for the handbook — it explains every system in the game.

Hover over any number to see what is driving it. Click the number for a full
breakdown and a graph. The game is meant to take its time; how fast you get
anywhere depends on how efficiently you play.

`README.txt` inside the zip has more, including what feedback is most useful
and what is already known to be broken.
